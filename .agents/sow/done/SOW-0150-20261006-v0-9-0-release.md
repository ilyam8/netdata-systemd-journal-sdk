### Assistant Understanding

Facts:

- Root `v0.8.2` and `go/v0.8.2` exist on `netdata/systemd-journal-sdk` and peel
  to `51bf47f1f905`. Rust `0.8.2` crates were published later from
  `8ad648a7b4d3` (SOW-0145).
- `netdata/systemd-journal-sdk` `master` was at `044de252f612`, which contains
  24 commits after `v0.8.2`, including the IndexedSnapshot surface.
- The local preparation clone's `origin` is the user's fork; `upstream` is
  `netdata/systemd-journal-sdk`. Release tags belong on the canonical
  repository.
- The Go module lives under `go/`, so the release needs both `v0.9.0` and
  `go/v0.9.0` on the same commit.
- Compared with the Rust `0.8.2` source at `8ad648a7b4d3`, the public
  `SdkError` enum gained `Cancelled` (`rust/src/journal/src/lib.rs`) and the
  public `JournalError` enum gained `WriterPoisoned`
  (`rust/src/crates/journal-core/src/error.rs`). Neither enum is
  `#[non_exhaustive]`. No other public Rust enum gained variants; new public
  struct fields belong to new structs only.

Inferences:

- `0.9.0` (minor) rather than `0.8.3` is appropriate. Both languages add public
  API, and the two Rust enum variants are source-breaking for consumers that
  match every variant without a wildcard arm. Under Cargo's pre-1.0 rules a
  minor bump keeps `^0.8` consumers on `0.8.x` until they opt in.

Unknowns:

- None for preparation. Publication prerequisites are recorded in SOW-0151.
