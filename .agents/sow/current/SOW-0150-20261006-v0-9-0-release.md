## Requirements

### Purpose

Publish a paired Rust/Go `0.9.0` release so consumers can use the indexed
snapshot, archive-state and strict index verification work merged after `0.8.2`
(SOW-0147, SOW-0148, SOW-0149).

### User Request

The user asked how to release after merging `044de252f612` and approved
starting a `0.9.0` release for both Rust and Go.

### Assistant Understanding

Facts:

- Root `v0.8.2` and `go/v0.8.2` exist on `netdata/systemd-journal-sdk` and peel
  to `51bf47f1f905`. Rust `0.8.2` crates were published later from a separate
  commit (SOW-0145).
- `netdata/systemd-journal-sdk` `master` is at `044de252f612`, which contains 24
  commits after `v0.8.2`, including the IndexedSnapshot surface.
- The local clone's `origin` is the user's fork; `upstream` is
  `netdata/systemd-journal-sdk`. Release tags belong on `upstream`.
- The Go module lives under `go/`, so the release needs both `v0.9.0` and
  `go/v0.9.0` on the same commit.

Inferences:

- `0.9.0` (minor) rather than `0.8.3` is appropriate: the release adds new
  public API surface in both languages. The Rust changes observed since
  `v0.8.2` are additive new types, functions and methods; a minor bump also
  avoids Cargo treating the new API as a `^0.8` compatible patch.

Unknowns:

- No Rust toolchain is installed on the preparation workstation; Rust build,
  test and `cargo publish` must run where a toolchain and crates.io credentials
  are available (user's environment or CI).

### Acceptance Criteria

- Rust workspace version, internal dependency pins and `Cargo.lock` workspace
  entries are `0.9.0`; verified by diff and by Rust CI/`cargo` build.
- Every active consumer install example identifies `0.9.0` (release-tagging
  skill scan).
- "Unreleased" indexed snapshot wording is replaced with versioned wording.
- Rust crates are published at `0.9.0` in dependency order after dry-runs.
- Annotated `v0.9.0` and `go/v0.9.0` exist on `upstream` and peel to the same
  merged release commit; `go list -m github.com/netdata/systemd-journal-sdk/go@v0.9.0`
  resolves.
- SOW audit and `git diff --check` pass.
